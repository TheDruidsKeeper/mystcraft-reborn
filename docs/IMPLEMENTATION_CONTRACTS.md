## Global rules
1. Target **NeoForge 26.1.2.104 / Java 25**. There is no compiler available while writing: every vanilla/NeoForge call must match `docs/API_CHEATSHEET.md` (read it fully first) or a verified pattern in `docs/TOOLCHAIN.md`. If a signature is not in the cheat sheet, prefer the simplest plausible API and mark the line with `// UNVERIFIED: <what you assumed>` so it can be found with grep.
2. `Identifier` (not ResourceLocation), `ValueInput/ValueOutput` for BE/entity save, `ItemStacksResourceHandler`/`FluidStacksResourceHandler` for inventories/tanks, `Level#isClientSide()` method, `player.sendOverlayMessage`, no `getDayTime`, no `ItemInteractionResult`, `useItemOn(ItemStack, BlockState, Level, BlockPos, Player, InteractionHand, BlockHitResult)`, `entityInside(..., InsideBlockEffectApplier, boolean)`, `neighborChanged(..., @Nullable Orientation, boolean)`, `affectNeighborsAfterRemoval` instead of `onRemove`, `Item#inventoryTick(ItemStack, ServerLevel, Entity, @Nullable EquipmentSlot)`, `appendHoverText(ItemStack, TooltipContext, TooltipDisplay, Consumer<Component>, TooltipFlag)`, `use(Level, Player, InteractionHand) -> InteractionResult`.
3. Never construct `ItemStack` in static initialisers. Use `org.jspecify.annotations.Nullable`.
4. Client classes only under `…client.**`; nothing outside may import `net.minecraft.client.*`.
5. Every mutable Age state change goes through `AgeData` setters (they mark the storage dirty).
6. Translation keys: `item.mystcraft.<name>`, `block.mystcraft.<name>`, `symbol.mystcraft.<path>`, `link_property.mystcraft.<name>`, `gui.mystcraft.<...>`, `commands.mystcraft.<...>`, `instability.mystcraft.<...>`, `entity.mystcraft.<name>`, `itemGroup.mystcraft.<tab>`. Collect every key you use in a list at the end of your package summary so the lang file can be generated.
7. When done, write `docs/impl/<package>.md`: list every public class with its constructor(s)/key methods and every lang key used. Other packages read this.

## Package B — world generation (`world/**`)
Provides (constructors are the contract; all implement the `api.symbol.logic` interfaces named):
- `world.AgeChunkGenerator(UUID ageId, BiomeSource)` + `public static final MapCodec<AgeChunkGenerator> CODEC` (fields: `age_id` as string uuid, `biome_source`). Looks up `AgeControllers.server(level)` lazily (the ServerLevel is obtained from the `WorldGenRegion#getLevel()`/`StructureManager` context; cache the controller on first use per generator instance via `AgeControllers.server(server, uuid)` using `ServerLifecycleHooks.getCurrentServer()`).
- `world.AgeBiomeSource(UUID ageId)` + `CODEC` — `getNoiseBiome` delegates to the controller's `BiomeController`; `collectPossibleBiomes` returns `possibleBiomes()` (fallback plains when no server).
- `world.biome.BiomeHeights` — `static float baseHeight(Holder<Biome>)`, `static float heightVariation(Holder<Biome>)` (table keyed by vanilla biome key / tags; defaults 0.1 / 0.2, ocean −1.0/0.1, mountains 1.0/0.5 etc.).
- Biome controllers: `world.biome.SingleBiomeController(Holder<Biome>)`, `TiledBiomeController(List<Holder<Biome>>, boolean gridScale)`, `NativeBiomeController(long seed, HolderLookup.Provider)` (wraps vanilla `MultiNoiseBiomeSource.createFromPreset(overworld)` + `RandomState`), `LayeredBiomeController(long seed, int zoom, List<Holder<Biome>>)` (GenLayer-like: island/fuzzy zoom/biome/zoom×n/smooth, spawn biomes list).
- Terrain generators: `world.gen.TerrainNormalGen(long seed, boolean amplified, BlockState terrain, BlockState sea)`, `TerrainFlatGen(long seed, BlockState terrain, BlockState sea)`, `TerrainNetherGen(long seed, BlockState terrain, BlockState sea)`, `TerrainEndGen(long seed, BlockState terrain, BlockState sea)`, `TerrainVoidGen()`. They generate into y ∈ [-64, 320); the original 0..128 noise field is mapped so that sea level stays 63 (i.e. generate as the original did for y 0..255 and leave y < 0 as terrain block down to bedrock at -64 for non-void/non-end generators).
- Alterations: `world.feature.CavesAlteration(long seed, int rate, int size, BlockState fill)`, `RavinesAlteration(long seed)`, `SpheresAlteration(long seed, BlockState)`, `FloatingIslandsAlteration(long seed, Holder<Biome>, BlockState)` (also `ChunkFinalizer`), `HugeTreesAlteration(long seed)`, `SkylandsAlteration(long seed)`.
- Populators: `world.feature.DenseOresPopulator()`, `LakesPopulator(BlockState fluid, boolean deep)`, `ObelisksPopulator(BlockState)`, `SpikesPopulator(BlockState)`, `CrystalFormationPopulator(BlockState)`, `StarFissurePopulator()`, `DungeonsPopulator()`, `VanillaStructurePopulator(String kind)` where kind ∈ `villages|strongholds|mineshafts|nether_fortress` (implement by placing the vanilla structure-set through the chunk generator's structure state if feasible; otherwise a documented no-op with `// TODO`).
- `world.structure.MystcraftLibrary` — places the library piece (Appendix B layout) as a `Populator` at 1 per 32×32 chunk region; loot chest `mystcraft:chests/library`; lecterns with rank≥3 pages via `item.PageItem.createSymbolPage`.
- `world.AgeSpawn.findSpawn(ServerLevel, AgeController) -> BlockPos` (§5.3 verifySpawn) and the 5×5 cobblestone platform at spawn.
The generator pipeline (§5.4): `fillFromNoise` = terrain gen → alterations (in order) → finalizers; `buildSurface` = vanilla-like surface replacement per biome (grass/dirt, sand, etc. — use `SurfaceRules`? not available without noise settings: implement a simple biome-keyed top/filler table); `applyCarvers` = no-op (caves are alterations); `applyBiomeDecoration` = vanilla `super.applyBiomeDecoration` (biome features) then populators + library.
