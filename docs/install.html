Install Mystcraft Reborn

Opens Prism Launcher and imports the latest playable instance (Minecraft 26.1.2 + NeoForge + this mod). Requires Prism and Java 25.

Install with Prism Download .mrpack

If the button does nothing, install Prism Launcher, then use Add Instance → Import and paste:

https://github.com/TheDruidsKeeper/mystcraft-reborn/releases/latest/download/mystcraft-reborn.mrpack

MultiMC / manual import:

  1. Download the MultiMC zip or the .mrpack above.
  2. Add Instance → Import → choose the file (or paste the URL).
  3. Launch. Prism should pull NeoForge and a Java 25 runtime if needed.
